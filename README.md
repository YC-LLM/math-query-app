# 數學參採小幫手｜大學校系數學採計查詢

仿「牛啤學長」風格做的查詢工具，讓考生快速篩選「哪些大學校系會檢定 / 採計 / 加權計算數學」。
純前端網頁（HTML + CSS + 原生 JS），資料分四層，**三層已是官方真實資料**：

| 資料層 | 檔案 | 管道 | 學年度 | 內容 | 來源 |
|---|---|---|---|---|---|
| ✅ 官方 | `naer_data.js` | 考試分發 | 111～114 | 數學採計加權（無核定名額／檢定門檻） | 使用者提供，國家教育研究院【數學課綱】研究案彙整試算表 |
| ✅ 官方 | `real_data.js` | 考試分發 | 115 | 完整校系分則（含加權倍率、核定名額、檢定標準） | 大學考試入學分發委員會 校系分則查詢系統（本專案爬取） |
| ✅ 官方 | `mathsys_data.js` | 繁星推薦・個人申請・考試分發 | 116／117 | 數學參採類型（**不含**加權倍率，簡章公告前預告資料） | 教育部 數學考科參採查詢系統（本專案爬取） |
| ⚠️ 示範 | `data.js` | 繁星推薦・個人申請 | 無 | 手工編寫的少量範例 | 非官方，僅供展示介面用 |

四層合起來涵蓋 111～117 學年度、共約 1.2 萬筆資料。繁星推薦／個人申請目前抓不到完整官方
資料，原因見下方「為什麼有些管道還是示範資料」。

## 密碼閘門（`gate.js`）

開啟網頁時會先看到一個要求輸入密碼的畫面，密碼正確才會顯示 App 內容。

⚠️ **這只是「擋路人」用的前端閘門，不是真正的存取控制**：本站是純前端靜態網頁
（GitHub Pages），沒有後端伺服器可以驗證密碼，任何打開瀏覽器開發者工具的人都能
繞過（直接看 `index.html`/`gate.js` 原始碼、或直接打開各 `*_data.js` 的網址取得
資料）。密碼用 SHA-256 雜湊比對、不是明文寫在原始碼裡，但雜湊本身仍公開可見，
一樣能被離線暴力破解，所以**不要用其他地方也在用的重要密碼**。如果需要真正防止
外流等級的保護，需要換成有後端驗證的方案（例如 Netlify 內建密碼保護、或自架驗證
伺服器），純前端做不到。

答對密碼後會記在瀏覽器的 `localStorage`（`math-app-unlocked-v1`），同一台瀏覽器
下次不用重新輸入；換瀏覽器、換裝置、或清除瀏覽器資料就要重新輸入。

## 怎麼開啟

因為瀏覽器對 `file://` 開啟本機 JS 檔案有安全限制，用雙擊 `index.html` 有時候會看到
畫面但篩選功能失效，建議在資料夾內起一個本機伺服器再打開：

```bash
cd math-query-app
python -m http.server 8000
```

然後瀏覽器開 `http://localhost:8000`。

## 檔案結構

- `index.html`　頁面結構、篩選介面（含學年度／科目／參採方式／管道／學群／地區篩選）
- `style.css`　外觀樣式（支援亮/暗色模式）
- `gate.js`　前端密碼閘門（僅供擋路人使用，見上方說明）
- `data.js`　示範資料（`MATH_QUERY_DATA`，僅繁星推薦／個人申請，31 筆）
- `real_data.js`　官方資料（`MATH_QUERY_DATA_REAL`，115學年度考試分發，624 筆）
- `mathsys_data.js`　官方資料（`MATH_QUERY_DATA_MOE`，116/117學年度三管道數學參採類型，3807 筆）
- `naer_data.js`　官方資料（`MATH_QUERY_DATA_NAER`，111～114學年度考試分發，7364 筆）
- `app.js`　合併四個資料來源、篩選邏輯與畫面渲染

`app.js` 會把所有資料的欄位（`mathScreen`/`mathCount`/`mathCounts`/`mathSubjects`，因
資料層而異）都正規化成統一的「檢定科目集合」「採計科目集合」，篩選介面不用區分資料
來自哪一層。

## 資料欄位說明

### `data.js`（示範資料，單一科目）

```js
{
  id, school, dept, type, region, group, channel, source,
  mathScreen,  // 檢定門檻：{ subject: '數學A'|'數學B', min: '頂標'|'前標'|'均標'|'後標'|'底標' } 或 null
  mathCount,   // 採計進總分：{ subject: '數學A'|'數學B'|'數學甲'|'數學乙', weight: 倍率 } 或 null
}
```

### `real_data.js` / `naer_data.js`（官方考試分發，可複數科目）

```js
{
  id, school, dept, type, region, group, channel, year, source,
  mathScreen,   // 只有 real_data.js 有；檢定門檻，格式同上，或 null
  mathCounts,   // 陣列：[{ subject, weight }, ...]，可能同時採計「學測數學A/B」
                // 與「分科測驗數學甲/乙」，各自有獨立加權倍率（例：台大數學系
                // 同時採計 數學A×1.5 與 數學甲×1.5）；不參採數學則為 []
}
```

`real_data.js` 另有 `code`（系組代碼）、`quota`（核定名額），`naer_data.js` 沒有
（來源試算表未收錄這兩欄）。

### `mathsys_data.js`（只有參採類型，沒有倍率）

```js
{
  id, school, dept, type, region, group, channel, year, source,
  mathSubjects,        // 該校系該管道實際參採的數學科目陣列，例如 ['數學A']、['數學A','數學甲']
  participationNote,   // 官方原文參採類型說明
}
```

- `mathScreen` = 「檢定門檻」，達標即可，不影響錄取總分。
- `mathCount`（單一物件）/ `mathCounts`（陣列）/ `mathSubjects`（陣列）= 實際「採計」進
  總分的科目；只有 `mathCount` / `mathCounts` 有 `weight`（加權倍率，1 = 正常占比，
  > 1 = 加權）。`mathSubjects` 只知道「有沒有採計」，不知道倍率。
- `source` 開頭是 `official-` 代表官方資料，卡片上會顯示綠色「✅ 官方OOO學年度」；
  否則顯示橘色「⚠️ 示範資料」。

## 官方資料是怎麼取得的

### `real_data.js` / `mathsys_data.js`（本專案爬取）

兩個來源都是**公開的互動查詢工具**，沒有開放 API 或批次下載：

- `uac2.ncku.edu.tw/cross_search`（考試分發校系分則）
- `srecruit.moe.edu.tw/mathsys`（數學參採類型，教育部）

擷取前**先查過兩者的 `robots.txt`，確認沒有 `Disallow` 限制**才動手（相對地，
「大學甄選入學委員會」cac.edu.tw 的 `robots.txt` 是 `Disallow: /`，全站禁止爬取，
因此繁星推薦／個人申請的完整資料目前拿不到，見下一節）。

做法是在瀏覽器內用 `fetch()` 重放這兩個查詢系統本身的表單送出邏輯（勾選所有含數學的
採計組合／參採類型 → 取得符合的校系清單 → 逐系呼叫官方的「詳細資料」端點），每筆請求間
加上延遲、控制並行數，避免造成伺服器負擔。real_data.js 共送出 1 次列表查詢 + 624 次
詳細資料查詢；mathsys_data.js 共送出 18 次列表查詢 + 1759 次詳細資料查詢。

### `naer_data.js`（使用者提供）

來自使用者國家教育研究院【數學課綱】研究案自行彙整的試算表
「111-115 考試分發_原始資料暨分析數據」，逐學年度（111～114）將學校、系組、公私立、
學類、學群、各科加權倍率整理成表；115 學年度因本專案已另行爬取（`real_data.js`）故
不重複收錄。原始試算表另有「頂大」欄位與各學年度「分析結果」統計表，依使用者指示
未收錄進資料集。

`group`（學群）欄位在 `real_data.js` / `mathsys_data.js` 是**依系所名稱關鍵字自動歸類**
（非官方分類）；`naer_data.js` 沿用使用者研究案自行歸類的學群，已統一改寫為與其他三層
相同的「OO學群」命名方式，方便合併篩選。

## 為什麼有些管道還是示範資料

1. **繁星推薦／個人申請（cac.edu.tw）**：`robots.txt` 全站 `Disallow`，不會爬取，
   目前 `data.js` 裡這兩個管道仍是少量手工示範資料。
2. 官方查詢系統都**沒有歷史資料庫**：每個查詢工具通常只保留「當年 + 未來 1~2 年預告」，
   簡章正式公告後舊年度就會下架、導去別的系統，所以考試分發以外的管道、以及
   「111 學年度以前」「118 學年度以後」的資料，目前都無法系統性取得。
3. `mathsys_data.js`（116/117）是簡章公告前的**預告資料**，正式簡章公告後可能調整，
   而且它只回報「參採類型」，沒有加權倍率、檢定門檻、核定名額。

## 如何補齊繁星推薦／個人申請資料

因為 cac.edu.tw 禁止爬取，比較可行的路是**人工**：
1. 自己以瀏覽器（非自動化工具）到 cac.edu.tw 下載「個人申請招生簡章」校系分則 PDF／查詢頁。
2. 依照 `data.js` 開頭註解的欄位格式整理成物件，貼進 `data.js`（或另開一個
   `cac_data.js`，仿照 `real_data.js` 的寫法，`app.js` 會自動合併載入，記得在
   `index.html` 加一行 `<script src="cac_data.js"></script>`）。
3. 若該管道完全不參採數學，`mathScreen` 與 `mathCount`/`mathCounts` 都填 `null`／`[]` 即可。

## 免責聲明

三層官方資料雖逐系對照官方頁面（或使用者提供的彙整試算表）產生，但**學群分類為
自動歸類或研究案自行歸類、非官方分類**，且不保證與官方頁面完全零誤差；「示範資料」
層則完全是手工編寫、非官方資料。任何情況都**不可作為升學申請依據**，正式查詢與
最終資訊請以 [大學甄選入學委員會](https://www.cac.edu.tw/)、
[大學考試入學分發委員會](https://www.uac.edu.tw/)公告簡章為準。
